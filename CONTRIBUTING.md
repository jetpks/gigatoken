# Contributing

> This file is upstream's, for the Rust engine at [marcelroed/gigatoken](https://github.com/marcelroed/gigatoken). For the Ruby bindings in *this* fork, open a GitHub issue or PR here instead.

Thank you for your interest in contributing to Gigatoken!

Unfortunately I don't have the capacity to review the large flood of PRs most open source projects are getting in the AI-coding age.
Contributions will thus be limited to submitting GitHub Issues.

## Requirements for an Issue

### Defining the problem
Please be clear about what the problem is and why solving it would outweigh the increase in complexity it would add to the codebase.

### No AI-written issues
Please do not submit AI-written "drive-by" issues.
It's fine to include AI summaries in links or provided context if they are relevant to the issue.

### Suggestion for how to solve the problem
Optionally, you can also link to a commit in your own fork of the repo to suggest an implementation for a fix or to prove that a fix is possible.
In this case, please don't make sweeping changes, and keep your diffs concise and relevant to the issue at hand.
Be clear about the amount of work you have put into the code you submit in this way, since it can be hard for me to tell at a glance the difference between something slopped together by AI in a few minutes vs a hand-crafted contribution.
Be clear about shortcomings and let me know if your code is missing some testing or other features before you deem it ready to be merged.
